# Build a RAG system on Jev

Retrieval by decisions, not vectors: Jev, a decision model, scores every passage against the question in one request, picks the document, says when nothing answers it, and checks every sentence of the reply. 20 functions, both models real.

Built step by step on [Deep-Agnt](https://deep-agnt.com/projects/jev-rag): 1 of 20 steps passed, each graded by tests.
